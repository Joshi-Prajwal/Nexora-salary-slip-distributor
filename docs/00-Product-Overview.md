# 00 — Product Overview

## Product Vision
The **Local Salary Slip Distribution Desktop Application** is a Windows-first local desktop tool designed specifically for HR and Payroll departments.

### Primary Purpose
Automate the discovery, matching, and secure distribution of pre-generated salary-slip PDF documents to employees via authorized WhatsApp Business API and Email providers.

### Key Business Constraints & Principles
1. **No Payroll Calculation**: The application does NOT calculate salary, taxes, deductions, or net pay.
2. **No PDF Document Generation**: Salary slips already exist as PDF files created by upstream payroll software.
3. **Local First Data Privacy**: Employee database and salary slip files remain on the user's local disk.
4. **Zero Risk Distribution**: Ambiguous employee-to-PDF matches MUST NOT be auto-sent. Human review is strictly enforced.
5. **Authorized Channels Only**: WhatsApp integration relies on official Meta/WhatsApp Business API solutions. Personal WhatsApp Web automation or browser scraping is strictly prohibited.
